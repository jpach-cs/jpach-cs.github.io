## Course Description
This course provides a comprehensive introduction to structured programming using the C language. Students will gain a deep understanding of memory management techniques such as pointers and dynamic allocation. The skills acquired in this course will be essential for those who wish to pursue further studies in languages like C++, C#, and Java, as well as microcontroller programming. Additionally, this course will lay a strong foundation for understanding computer architecture.

## Student Learning Outcomes

 Upon successful completion of this course, students will demonstrate the ability to:

* Demonstrate knowledge of program structure and organization, including data types, variable declarations, and initialization.

* Distinguish between local, global, and static variables, and understand their scope and lifetime within a program.

* Effectively use unary, binary, and ternary operators in the C programming language.

* Construct and implement control structures and loops for managing program flow.

* Define and utilize complex data structures, including structures, unions, and enumerations.

* Make use of built-in libraries for common programming tasks.

* Work with pointers, including pointers to variables, labels, and functions.

* Demonstrate the ability to perform dynamic memory allocation in their programs.

* Manage file operations, including reading from and writing to files.

* Implement basic error handling mechanisms in their code.
