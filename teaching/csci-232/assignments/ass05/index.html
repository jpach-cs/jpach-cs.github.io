Instructions

  1. Fork the repository on GitHub: https://github.com/jpach-cs/232-ass05-template
  2. Clone your forked repository to your local machine.
  3. Open src/code.cpp and src/tests.cpp and include/code.hpp.

  1. Work through each function and class method in two parts:

Part 1 — Legacy Data & Node Integration (src/code.cpp)

  • Implement printLegacyData to safely handle legacy C unions in C++.
  • Implement node initialization and helper creation functions for struct, classNodeVariant, and template nodes.
  • Do not modify function signatures in include/code.hpp.

Part 2 — LinkedList Class Implementation (src/code.cpp)

  • Implement RAII memory management in the constructor and destructor.
  • Implement member methods for insertion, deletion, searching, and traversal.
  • Ensure all methods handle nullptr guards and empty list edge cases.

Part 3 — Unit Tests (src/tests.cpp)

  • Implement unit test bodies using TEST_ASSERT_.
  • Clean up any dynamically allocated memory in test cases to prevent leaks.
  1. Build and run locally using C++20 (g++):
make clean
make
./run_tests
  1. When all local tests pass — commit and push to your repository.
  2. Go to the Actions tab on GitHub and verify the CI results.

Method Description

  • Always guard against nullptr when dereferencing pointers.
  • Always clean up dynamically allocated nodes (delete) in tests and destructor.
  • CI runs your tests05.cpp together with instructor validation tests — both must pass.
