# CSCI 361 — Computer Architecture

## Course Overview

This course explores the design and organization of computer systems, including the instruction set and 
interconnection of hardware components. Topics include computer performance, assembly language programming, 
microprocessor architecture, pipeline processing(parallel computing), memory and storage organization, and 
multiprocessor computers. Will consist of many small programming problems.
