Background

For Loops vs While Loops

Use for loops when you know the iteration count:

for (int i = 0; i < n; i++)
{
    // Process array[i]
}

Use while loops when you don’t know when to stop:

int i = 0;
while (i < n)
{
    if (/* found it */)
        return i;
    i++;
}

Include Guards

Header files must use include guards to prevent multiple inclusion:

#ifndef CODE_H
#define CODE_H

#endif

Heron’s Method for Square Root

Background:

Heron’s method iteratively improves an initial guess:

next_guess = (current_guess + x / current_guess) / 2.0

Stop when consecutive guesses differ by less than epsilon.

Algorithm:

  1. Start with initial guess: guess = x / 2.0
  2. Use while (1) loop (infinite loop with break):
    • Save current guess: prev_guess = guess
    • Calculate next guess: guess = (guess + x / guess) / 2.0
    • Calculate difference: diff = guess - prev_guess
    • Make difference positive manually: if (diff < 0) diff = -diff;
    • If diff < epsilon, break the loop
  3. Return the final guess

Note: You cannot use fabs() - manually check if negative with if (x < 0) x = -x;

Example: heron(4.0, 0.0001); // Returns ≈ 2.0 heron(9.0, 0.0001); // Returns ≈ 3.0 heron(2.0, 0.0001); // Returns ≈ 1.414
