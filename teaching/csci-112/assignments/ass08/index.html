Learning Objectives

After completing this lab, you will:

  • Create, read, append to and clear files in text mode ("w", "r", "a")
  • Create, read, append to and clear files in binary mode ("wb", "rb", "ab")
  • Write and read text with fprintf() / fscanf()
  • Write and read raw bytes with fwrite() / fread()
  • Navigate a binary file with fseek() and ftell()
  • Handle errors (fopen() returning NULL)
  • Use the math functions: abs(), fabs(), sqrt(), pow(), ceil(), floor(), round(), fmod()

General rules

  1. Every function that returns bool returns true on success and false on any failure (fopen() failed, invalid argument, read/write error).
  2. Always check the result of fopen().
  3. Always close every file you open (also on error paths after a successful fopen()).
  4. If an argument is invalid (see each function), return false without touching the file (do not create, truncate or modify it).
  5. All floating point numbers in text files are written with exactly two digits after the decimal point: "%.2f\n". Integers are written with "%d\n". Every value is on its own line and every line ends with \n.
  6. In binary files an int is stored as sizeof(int) bytes and a double as sizeof(double) bytes, with no separators and no extra data.

append_sqrt_bin("b.bin", 9.0)         -> b.bin: [3.0][2.0][3.0]                  (3 * sizeof(double) bytes)

Background

Opening and closing a file

FILE *f = fopen("data.txt", "w");
if (f == NULL)
{
    return false;       // always check!
}
fprintf(f, "%d\n", 42);
fclose(f);              // always close!
return true;

Modes you need

Mode Meaning
"w" / "wb" Write. Creates the file, erases existing content.
"a" / "ab" Append. Creates the file if needed, adds data at the end.
"r" / "rb" Read. The file must exist.

Text vs. binary

// text: human readable
fprintf(f, "%.2f\n", 3.5);          // writes the characters 3 . 5 0 \n
fscanf(f, "%lf", &x);               // reads a double (note: %lf for double)

// binary: raw bytes
double d = 3.5;
fwrite(&d, sizeof(d), 1, f);        // writes sizeof(double) bytes
fread(&d, sizeof(d), 1, f);         // returns the number of elements read

Moving around a binary file

fseek(f, index * sizeof(double), SEEK_SET);   // jump to the index-th double
fseek(f, 0, SEEK_END);                        // jump to the end
long size = ftell(f);                         // current position = size in bytes

Math functions

Function Header Meaning Example
int abs(int) stdlib.h absolute value of an integer abs(-7) → 7
double fabs(double) math.h absolute value of a double fabs(-2.5) → 2.5
double sqrt(double) math.h square root sqrt(16.0) → 4.0
double pow(double, double) math.h power pow(2.0, 10.0) → 1024.0
double ceil(double) math.h round up ceil(2.3) → 3.0
double floor(double) math.h round down floor(2.7) → 2.0
double round(double) math.h round to nearest (halves away from zero) round(2.5) → 3.0
double fmod(double, double) math.h floating point remainder fmod(7.5, 2.0) → 1.5

Note: when compiling by hand, programs using math.h functions may need the -lm flag: gcc main.c code.c -o main -lm

Local Testing (Sandbox)

Create test cases in main.c:

#include <stdio.h>
#include "code.h"

int main()
{
    // Text mode
    create_abs_txt("test.txt", -7);
    append_sqrt_txt("test.txt", 16.0);
    append_pow_txt("test.txt", 2.0, 10.0);
    append_round_txt("test.txt", 2.5);
    append_fmod_txt("test.txt", 7.5, 2.0);

    double values[10];
    int n = load_txt_values("test.txt", values, 10);
    printf("Read %d values from text file:\n", n);
    for (int i = 0; i < n; i++)
    {
        printf("  %f\n", values[i]);
    }

    clear_file("test.txt");
    printf("Size after clear: %ld\n", get_file_size("test.txt"));

    // Binary mode
    create_ceil_floor_bin("test.bin", 2.3);
    append_sqrt_bin("test.bin", 9.0);
    append_pow_bin("test.bin", 3.0, 2.0);

    n = load_bin_values("test.bin", values, 10);
    printf("Read %d values from binary file:\n", n);
    for (int i = 0; i < n; i++)
    {
        printf("  %f\n", values[i]);
    }

    double v;
    if (load_bin_value_at("test.bin", 2, &v))
    {
        printf("Value at index 2: %f\n", v);
    }
    printf("Binary file size: %ld bytes\n", get_file_size("test.bin"));

    create_abs_bin("abs.bin", -42);
    int iv;
    if (load_abs_bin("abs.bin", &iv))
    {
        printf("abs.bin: %d\n", iv);
    }

    return 0;
}
