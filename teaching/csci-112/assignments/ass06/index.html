Background

Structs and Pointers

When passing structs to functions, use pointers for modification:

struct Point { int x; int y; };

void init_point(struct Point *p, int x, int y) { p->x = x; // Use arrow operator -> with pointers p->y = y; }

Function Pointers

A function pointer stores the address of a function. Declare it like:

float (*operation)(float, float); // Pointer to function taking two floats, returning float

Call the function through the pointer:

float result = operation(a, b); // Just like calling a regular function

IMPORTANT: When assigning a function to a pointer, use the function name directly (NO &):

operation = add; // Correct operation = &add; // Also works but redundant

Structs with Function Pointers

You can have struct members that are function pointers:

struct Calc { float a; float b; float (add)(float, float); float (sub)(float, float); };

// Then use it: calc.add(calc.a, calc.b);

Typedef

Create type aliases to simplify declarations:

typedef struct double_Point { double x; double y; } DoublePoint;

// Now you can use: DoublePoint p; instead of: struct double_Point p;

Function Pointers as Parameters

Pass functions as parameters to implement callbacks:

double apply_operation(float arr, int length, float (operation)(float, float)) { float result = arr[0]; for (int i = 1; i < length; i++) { result = operation(result, arr[i]); // Call the passed function } return (double)result; }

// Usage: double sum = apply_operation(arr, 4, add); // Pass add function double product = apply_operation(arr, 4, mul); // Pass mul function
